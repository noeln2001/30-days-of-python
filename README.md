# 🐍 PyMaster 30 — 30 Days of Python Interactive Studio

> **Live Application:** [https://noeln2001.github.io/30-days-of-python/](https://noeln2001.github.io/30-days-of-python/)

An interactive, in-browser Python learning studio and coding playground based on the comprehensive 30 Days of Python curriculum.

---

## 🌟 Key Features

- **📘 Complete 30-Day Curriculum**: All 30 days formatted with syntax highlighting, notes, tables, and "Try in Playground" one-click execution.
- **💻 Guided Practice & Automated Test Verifier**: Hands-on coding challenges for each day with instant assertion feedback, hints, and model reference solutions.
- **⚡ In-Browser Python WebAssembly**: Powered by **Pyodide**, enabling real Python 3 execution directly in your browser with zero server latency.
- **💬 Interactive Python REPL**: Real-time `>>> ` console with history navigation for testing expressions on the fly.
- **🧠 Daily Concept Quizzes**: 90+ conceptual multiple-choice questions with immediate explanations.
- **📑 Python Cheat Sheet**: Searchable reference for built-in functions, strings, lists, dictionaries, regex, and error types.
- **🔥 Progress Tracking & Streaks**: Auto-saved progress, streak tracking, and celebratory confetti upon completing exercises.

---

## 🚀 Running Locally

You can also run the studio locally on your computer with your local Python interpreter:

```bash
# Clone the repository
git clone https://github.com/noeln2001/30-days-of-python.git
cd 30-days-of-python

# Launch the interactive server
python server.py
```
Or simply double-click `start_app.bat` on Windows.
